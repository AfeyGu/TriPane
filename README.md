# TriPane — 多屏窗口分组管理器 for Windows

**TriPane** 是一个轻量级的 AutoHotkey 工具，将每块屏幕上的窗口分为三个类别：**第一组**、**第二组**和**其他**（未分类）。横屏时左右分屏，竖屏时上下分屏。通过快捷键分配窗口、按组切换焦点，重新掌控你的键盘工作流。

---

## 为什么用 TriPane？

- **键盘优先**：分配、恢复、切换、交换——全程无需触控鼠标。
- **多屏适配**：每块屏幕独立管理，横屏/竖屏自动检测，无需配置。
- **三分类**：两组固定 + 一个"其他"池，容纳那些不常聚焦但又不愿关闭的应用。
- **左手快捷键**：Q / W / E / 1 / 2 / 3 核心操作键——任何用过键盘的人都能自然上手。

---

## 快捷键

### 核心操作

| 按键    | 动作             | 说明                                           |
| ------- | ---------------- | ---------------------------------------------- |
| `Alt+Q` | 分配到**第一组** | 横屏→左半屏，竖屏→上半屏                       |
| `Alt+E` | 分配到**第二组** | 横屏→右半屏，竖屏→下半屏                       |
| `Alt+W` | **移出分组**     | 恢复到原始位置（或居中 800×600），标记为"其他" |

### 分组切换

| 按键    | 动作           | 说明                         |
| ------- | -------------- | ---------------------------- |
| `Alt+1` | 切换**第一组** | 在当前屏幕的第一组窗口间循环 |
| `Alt+2` | 切换**其他**   | 在当前屏幕的未分类窗口间循环 |
| `Alt+3` | 切换**第二组** | 在当前屏幕的第二组窗口间循环 |

### 工具

| 按键    | 动作      | 说明                                             |
| ------- | --------- | ------------------------------------------------ |
| `Alt+J` | 显示状态  | 弹出全部分组统计（各组数量、屏幕方向、跨屏汇总） |
| `Alt+R` | 交换两组  | 交换当前屏幕第一组和第二组的所有窗口位置         |
| `Alt+A` | 100% 全屏 | 窗口填满当前显示器工作区域，移出分组             |
| `Alt+S` | 80% 大小  | 窗口缩放至屏幕 80%，居中，移出分组               |
| `Alt+D` | 60% 大小  | 窗口缩放至屏幕 60%，居中，移出分组               |

## 工作原理

### 数据模型

每块屏幕独立维护两个分组：

- **第一组** — 横屏=左侧，竖屏=上方
- **第二组** — 横屏=右侧，竖屏=下方
- **其他** — 当前屏幕其余未分类窗口（隐式，无需显式存储）

### 分配流程

1. 窗口原始位置被保存（仅首次）。
2. 窗口从对方分组移除（如存在）。
3. 窗口被定位到当前显示器的对应半屏。
4. OSD 短暂显示确认动作。

### 移出分组

- 回到保存的原始位置和尺寸。
- 无原始状态时，以 800×600 居中显示。

### 切换逻辑

每个分组维护按插入顺序的列表。切换时循环激活列表中的下一个窗口。已关闭的窗口会被自动清理（每秒定时扫描）。激活使用 `SetForegroundWindow` API 确保窗口可靠提到前台。

### 启动时自动分类

TriPane 启动时扫描所有已有窗口。任何已经吸附到半屏的窗口会被自动归类到对应分组。重启不会丢失你的布局。

### 窗口过滤

自动排除以下窗口：

- 桌面、任务栏、系统外壳（Progman、WorkerW、Shell_TrayWnd 等）
- 不可见窗口（无 WS_VISIBLE 样式）
- 无任务栏入口的工具窗口（WS_EX_TOOLWINDOW）
- DWM 隐藏的挂起窗口（如后台 UWP 应用）
- 无标题的系统/辅助窗口

## 托盘菜单

右键托盘图标可访问：

- **显示分类状态** — 同 `Alt+J`，弹出完整统计
- **重新加载** — 重载脚本

## 自定义

### 快捷键

编辑 `TriPane.ahk` 中对应的热键标签。例如，将分配第一组从 `Alt+Q` 改为 `Alt+J`：

```autohotkey
!q::        ; 将 !q:: 改为 !j::
```

### OSD 显示时长

找到 `SetTimer, HideOSD, -800`，调整 `800`（单位毫秒）。

### 窗口排除

在 `IsExcluded()` 函数中添加或移除条件，以精细控制 TriPane 忽略哪些窗口。
